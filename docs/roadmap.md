# 后续演进

当前版本提供可复算、低消耗的本机观察闭环。后续工作优先按可验证的新增价值推进。

| 方向           | 新增价值                               | 验收方式                                               |
| -------------- | -------------------------------------- | ------------------------------------------------------ |
| Codex稳定集成  | 从私有IPC迁移到公开停止接口或正式插件  | 指定版本的可丢弃测试会话实机验收，包括不可用与部分失败 |
| 用户题库       | 接入更贴近个人工作的领域题             | 版本化schema、确定答案、导入校验、独立oracle与成本预览 |
| 校准探针集     | 区分基础检查和不同难度，减少单题偶然性 | 固定模型/参数上的重复试验与分维度报告                  |
| 可选变点告警   | 发现持续质量变化，降低孤立错误的噪声   | 历史回放测误报/漏报，不替代当前单次答错保护规则        |
| 长期历史       | 超过1000条的归档与低开销查询           | 原子迁移、恢复测试、容量与延迟基准                     |
| 供应商兼容档案 | 更快定位分组/协议/参数差异             | 脱敏协议夹具；不静默重试，不增加用户账单               |
| 英文界面       | 让海外用户无需理解中文使用面板         | 词条完整性与双语言浏览器验收                           |
| 系统级后台安装 | 登录启动、状态菜单和跨平台电源保持     | 明确用户开关、卸载恢复、真实重启与睡眠耐久验收         |

欢迎将这些方向细化成小型PR。功能设计需保留明确预算、可解释判定、本机数据与可复算记录。
