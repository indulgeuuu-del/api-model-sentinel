# 探针、标准答案与判定

## 原糖果题

原题完整保存在 `src/probes.cjs` 的 `ORIGINAL_PROMPT`，版本 `original-user-v1`，固定答案21。请求中不加入答案，不提供工具或记忆内容。

这里采用形状可凭手感区分、可以预先安排圆形与星形数量的抽取策略。如果题目被理解为完全不能选择形状，答案会变成28；新增糖果变体因此明确写出形状配额，固定原题则保留用户选择的文字。

设圆形苹果/桃子/西瓜数量为 `a,b,c`，星形苹果/桃子/西瓜为 `d,e,f`，预先选择取 `r` 颗圆形和 `s` 颗星形。存在失败抽样，当且仅当下列情况至少一个成立：

- `r <= c`：圆形可能只有西瓜。
- `s <= f`：星形可能只有西瓜。
- `r <= b+c` 且 `s <= e+f`：两种形状都可能没有苹果。
- `r <= a+c` 且 `s <= d+f`：两种形状都可能没有桃子。

枚举所有合法 `(r,s)`，排除上述失败区间，取最小 `r+s`。算法在本机运行，不请求额外模型裁判。测试使用独立穷举每种口味/形状抽样数量的oracle核验小袋子全部64组数量组合，并检查原题答案。

## 五维轮换

选择轮换时，每周期仍只发一题，依次轮换五类，每次使用加密随机源产生32位种子；记录中保存种子、题目、版本、标准答案，可精确复算。

| 维度          | 生成与求解                       | 观察内容               |
| ------------- | -------------------------------- | ---------------------- |
| candy         | 六类数量变化，枚举形状配额       | 对抗最坏情况的约束推理 |
| arithmetic    | 带括号的整数表达式，直接运算     | 运算顺序与计算         |
| shortest-path | 六节点正权有向无环图，拓扑最短路 | 图结构与多步选择       |
| table         | 七行数据，奇数ID与库存阈值过滤   | 筛选、边界与汇总       |
| json          | 去重、排序、求和并输出两个字段   | 结构化指令与精确值     |

生成版本为 `generated-v1`。变更题意或求解器时必须升级版本并补回归用例，不能悄悄改变历史的标准答案。新题与固定题分别统计，参数和分组变化也会隔离统计。

## 判定边界

整数题使用最终数值token：可接受全角数字及附带解释，以最后一个可安全解析的整数为准。小数、分数、指数、超出JavaScript安全整数范围或无数字不强行取整。这个宽松规则适合观察内容正确性；它不会检查“只答整数”的格式服从情况。

JSON题需要可解析的对象，字段与值必须和标准答案完全一致，字段顺序不限，多余字段计为错误；无法解析的输出计为未能判定。原始答复始终保留，方便复核。

正确的可解析答案通过；供应商的超预算和推理用量只产生提示。完整终答中的确定错误计为失败。未完成或缺少完成状态的错误、拒答、空答案、网络故障和超时不触发自动保护。供应商返回模型名作为未经验证的自报信息展示。

## 统计与费用

通过率是 `正确 / (正确+错误)`。Wilson95%区间体现小样本的不确定性，不是对任意未来任务的能力保证。近期窗口是最新20个可判定结果，基线是此前最多80个，基线至少10个时显示对比；顺序依赖样本的区间只作描述，不自动进行模型身份推断。

请求可用率是完整响应数除以非取消请求数；不完整但可判定正确的答案可以通过，却不计入完整响应数。P50/P95仅用完整响应的耗时。token总量只累加供应商报告值；未报告时标为未知，不估算美元费用。

轮换和同题比较增加覆盖面，但各维题目难度并未校准，不应将不同混合比例的总通过率直接当作排行榜。比较时两端拿到完全相同的随机题，仍需对齐预算、推理强度、温度和分组设置。
