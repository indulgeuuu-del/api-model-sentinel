首个公开发行版：将原型整理为独立、本机运行的API质量监测工具。

- Responses / Chat、多配置后台调度、关闭浏览器继续运行。
- 保留原糖果题与低token默认值，增加五维可复算变体、同题比较与分组统计。
- 正确性与费用提示分开；超时和接口错误继续，完整答错才暂停。
- 加密持久化、崩溃恢复、无Key配置导出、脱敏历史与CSV公式防护。
- 双击启动/停止/演示、跨平台核心测试、桌面/移动浏览器验收。

安装Node.js22.14+后解压ZIP即可运行，无需安装运行时依赖。Windows双击Start.cmd；Demo.cmd不消耗API额度。SHA-256文件用于核验下载文件完整性。
